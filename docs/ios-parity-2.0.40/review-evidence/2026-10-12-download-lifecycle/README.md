# 下载调度、后台交接与持久记录保护

日期：2026-10-12。Android固定696e80a/2.0.40/340；从49446de接续的本地候选，不包含在正在运行的第十三轮Apple CI中。P4/P5未通过，真实站源继续后置，用户只做最后总验收。

冻结Android的DownloadService每2秒调度。旧iOS仅在网络从不可用变可用或用户操作时调度，已恢复任务在网络状态未变化时可能停住；nextAttempt已落盘却没有计时唤醒。当前运行器补独立重试计时、启动网络通知调度、Wi-Fi策略切换及后台暂停/前台恢复。已发布页复用，手动暂停保持；同一身份旧工作者退出前不启动新租约，完成回调必须确认租约仍有效。

新增UIKit生命周期桥接：申请系统有限后台时间，到期或拒绝时在工作线程保存可恢复租约；前台按顺序继续。回调携带代次，避免迟到活动状态覆盖新状态；主线程不读取可能等待文件操作的运行器锁。下载中心有实际后台限制说明。这不能提供Android前台服务的无限持续运行，必须另验真实设备系统配额。

同时确认下载数据库部分写入使用try?并提前更新内存。现改为原子写入失败回滚、返回实际结果、保留错误；队列领取/进度/完成不能在写入失败时返回成功。多个入队任务与删除租约失效以单次数据库事务保存。页归属先落盘再发布图片，记录失败不发布无归属的最终图片。出错后停止调度，下载中心显示保存失败和“重试保存并继续”；重试必须实际写入，再恢复有效任务，不删除旧记录、手动暂停、已发布页或用户原包。队列操作及网络策略落盘移至工作线程。
