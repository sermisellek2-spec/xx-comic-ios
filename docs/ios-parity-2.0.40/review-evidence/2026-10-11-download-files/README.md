- Files目录选择的探针、作品归属标记、目录创建、图片校验/读取/发布、空间统计和删除均在同步文件协调访问内完成；外部权限由持续目录书签管理。网络下载先写私有暂存目录，下载期间不持有文件提供器访问锁，完成后复制到目标卷并原子发布。
