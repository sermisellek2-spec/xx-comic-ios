# iOS 与 Android 2.0.40 当前差异核对

核对日期：2026-10-11。Android 冻结基线为 **2.0.40 / versionCode 340**，提交 `696e80a44ab36b19de6f630565df32978e55a19e`。本轮 iOS 从 `1e2287c7e5bcd51d84507a477ff68db3b66a6421` 工作树继续修正；成功 CI 和现有 IPA 对应较早的 `a5aeec90a1d47b9670b859150cb89f78c9856fbb`。两者不能混作同一版本的证据。

**当前仍未满足功能、视觉和交互 1:1。** 已有书架、搜索、详情、阅读、本地导入和下载入口，但存在实际遗漏和流程错误；设置、详情和阅读控制条也有明显应用样式差距。不能继续沿用“主要闭环都有，所以仅剩少量平台差异”或“全部通过”的结论。

## 对齐口径

- 当前 Android 功能保留；用户明确淘汰的左右手翻页删除，包括旧设置文案、偏好消费和反向手势映射。
- 冻结 Android 的“日漫模式”在 `ReaderSettingsSheet.toLeftHand` 中映射为同一个左右手反向设置。本轮按用户淘汰左右手的口径处理这一关联入口；这是产品范围调整，不能声称冻结 Android 自身已无该代码。
- 更新、Files 授权和后台调度可以按 iOS 机制完成同一用户结果。未实现的目录选择、删除撤销或布局粗糙不属于平台限制。
- **站源总数、ID、名称、默认顺序、默认启用状态和退役规则均须一致。** 数量对齐不代表实际网站已经可用。
- 先完成非站源功能、交互和视觉验收，最后才逐一验收真实网站；本轮没有新增真实站点测试。

## 站源目录：51 个，默认开启 50 个

冻结 Android 的 `defaultSourceOrder()` 提供 22 个专用源，公共 JSON 中 `available=true` 的 29 个源接在后面，总计 **51 个当前源**。`duya`（毒牙漫画）默认关闭，另 50 个默认开启；`haoman` 是不可用公共配置，不进入当前目录。

iOS 原生产管理目录含 **52 个**，把已退役的 `baozimh` 重新列为可启用源，专用源顺序也不同。本地现在采用统一 `BuiltinSourceCatalog`：管理、发现、全站搜索和配置导出只引用当前 51 个；`baozimh`、`mhua5` 仅用于旧记录身份和离线内容兼容，不重新开启网络请求。旧报告把 `mhua5` 写成 `manhuawu`，本轮已纠正。

专用源冻结顺序：

`mh160 → gmh → mh18 → jmcomic → mkzhan → hiperdex → manhuagui → hanman18 → d5d6 → manben → manhuazhan → bbyin → antbyw → cuimh → liumanhua → copy4000 → manwa → dingmanhua → dongmanla → xinmanhua → zaimanhua → guazi`

逐源名称、类型、顺序和默认值见 [sources.csv](../ios-parity-2.0.40/sources.csv)，冻结对象抽取与静态对比见 [source-catalog-proof.json](../ios-parity-2.0.40/review-evidence/2026-10-11-current-comparison/source-catalog-proof.json)。核心测试已覆盖新安装、旧开关/别名迁移和恢复默认排序；实际 51 个生产适配器的注册与名称有新增 Apple 单测，尚未执行。

## 仍须补齐的功能与交互

| 优先级 / ID | Android 当前行为 | iOS 当前差距 | 必须完成的闭环 |
| --- | --- | --- | --- |
| P1 / D23 | 书架徽标显示未读数量，网格/列表显示最新章；刷新保存作品锚点 | 只有“更新”字样；最新章信息和滚动锚点接线不足 | 根据真实阅读位置与最新目录计算数量；刷新/追更/换布局后保持可见作品和位置 |
| P1 / D24 | 本地删除先移出，延迟提交，提供撤销 | 本地合集删除是确认后直接删除 App 副本，无撤销窗口 | 撤销恢复书架与分组；到期仅清已确认归属副本；下载书同时协调任务；原文件和历史保留 |
| P1 / D25 | 选择下载位置并恢复授权，实际下载使用该目录及可读命名 | 无可用目录选择入口；`DownloadNamingPolicy` 有核心代码，不代表实际队列消费 | 使用 Files 授权/书签或可审查的等效存储与导出方案；权限失效可重授权；新任务实际写入并离线可读 |
| P1 / D26 | 清缓存有明确结果，保留下载和原包 | 两处清理在主线程遍历/删除，`try?` 吞错仍报成功；未清 `RemoteImageView` 内存缓存；本地空间统计也有主线程递归 | 后台计算/清理已确认的缓存范围，取消与代次保护，显示实际失败；内存/磁盘均处理且不误清下载 |
| P1 / D30 | 当前源配置实际影响对应请求 | `HiperdexComicSource()` 注册忽略导入配置，且缺少对应默认配置接线 | 用隔离 HTTP 响应验证域名/referer/routes/filters 真正消费；不支持项明确拒绝，不能静默成功 |

书架长按基线是**单本管理**，不是批量选择；不会为“对齐”新增 Android 当前没有的书架多选功能。批量导入与下载批量管理则是现有能力，需保留。

## 下一步验收顺序

先修复书架信息与撤销、下载位置/消费者、缓存线程与错误反馈、站源通用配置，然后对齐导航/设置/详情/阅读控制条，并在当前版本执行 Apple 构建和非站源运行矩阵。补齐双端同内容视觉和 Files、后台、恢复/性能证据后，才能判定非站源门槛通过。随后按 51 个源逐一验收搜索、分类、详情、目录、图片、下载和验证，最后产出版本一致、图标完整的新 IPA 供一次总验收。
