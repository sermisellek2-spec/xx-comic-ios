## 用户总验收建议

Gemini提供同一套固定样例和可重复步骤，用户按真实使用确认以下结果即可，无需替开发重跑所有技术检查。

1. 双端并排检查三主页面、长名/空态/错误态、抽屉和主题；在iPhone/iPad各检查横竖屏布局。
2. 书架分组、网格/列表、收藏/追更、就地换源、历史续读操作与原版一致。
3. 搜索、分类、详情、目录和验证返回形成完整闭环；取消和返回无状态错乱。
4. 条漫/单页、缩放、进度预览、目录跳转、原图/增强/AI2x、退出重启续读一致；日漫和左右手翻页不属于当前版本功能。
5. 导入真实书包/电子书/PDF/文件夹，完成批量恢复、分卷和自动同步；删除不会破坏原文件。
6. 下载暂停/重试/重启/完成后在本地书架断网阅读；位置和Wi-Fi设置重启有效。
7. 核对51个当前源及默认顺序/开关（默认开启50、duya关闭，退役baozimh/mhua5只兼容）；真实源按Gemini已自验清单抽查，外部不可用情况与报告一致，不以全可用假象交付。
8. 核对平台差异、安装说明和已有数据迁移；记录用户发现的问题并由Gemini修复后做影响范围自验。

用户发现问题仍由Gemini负责定位、修复和验证，不能把总验收变成反复补开发证据。
