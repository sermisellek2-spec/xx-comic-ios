## 二、站点外部限制与台账记录

- **外部站点限制**：漫画160 官方搜索接口 `/statics/searchelxt1e1.aspx` 启用了 Cloudflare 人机验证防护，非浏览器直连会收到 403 挑战；
- **非缺陷依据**：经核验，官方网站 PC 端表单 action 确实为 `/statics/searchelxt1e1.aspx`，iOS 适配器与 Android 2.0.40 基线实现完全一致；
- **用户使用路径**：用户可通过“分类筛选”、“发现推荐”、“最新更新”或“历史/收藏书架”正常浏览、阅读和离线下载全部漫画；
- **状态更新**：在 `sources.csv` 中将 `mh160` 状态标记为 **已适配 (部分功能受外部Cloudflare限制)**。
