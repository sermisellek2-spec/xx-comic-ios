# 拷贝漫画站源

内置 ID：`copy4000`；网页域名：`https://www.copy4000.com`；目录和阅读 API：`https://api.manga2026.xyz`。

已接入站源开关、全局搜索、站内搜索、分类分页、详情、目录、阅读解析、配置导入导出和图片 Referer。漫画主键为 `copy4000:{path_word}`，避免与其他站源混淆。

## 请求和解析

| 功能 | 路径／处理 |
|---|---|
| 搜索 | `/api/kb/web/searchci/comics`；platform=2，limit=12，offset=(page-1)*12，q_type 为空 |
| 分类字典 | `/filter`，动态读取题材 slug，保留大小写 |
| 分类列表 | `/comics`；limit=50，offset=(page-1)*50；读取 `.exemptComic-box` 的 list 属性 |
| 详情 | `/comic/{path_word}`，直接解析 HTML，目录按需另取 |
| 目录分组 | API `/api/v3/comic2/{path_word}?platform=3`，读取 results.groups |
| 目录分页 | API `/api/v3/comic/{path_word}/group/{group}/chapters?limit=100&offset={offset}` |
| 阅读 | API `/api/v3/comic/{path_word}/chapter/{uuid}?platform=3`，读取 results.chapter.contents |

筛选顺序：排序、题材、地区、状态。地区和状态的 `0` 为有效取值；全部选项不发送参数。分类 list 是实体编码的数据字面量，通过受限解析器读取，不执行网站 JavaScript。

API 地址来自[站点下载页](https://www.copy4000.com/download)提供的官方 3.0.9 安装包（20260622）。请求头为 `User-Agent: COPY/3.0.9`、`Accept: application/json`、`platform: 3`、`version: 3.0.9`、`region: 1`、`webp: 1`，并携带站源 Referer；无需账号 Cookie。

目录遍历所有分组，使用分页响应的 total 与实际返回条数推进 offset，不用分组 count 截断（实测 count=189，目录实际190条）。中途空页、重复页、漫画/分组标识错误均报错，避免保存不完整目录。图片按 contents 原顺序读取，并核对章节 uuid、漫画标识和 size。接口明确返回 is_lock 时报告不可访问。

站源配置新增 `apiBaseUrl`、`apiDetail`、`apiChapters`、`apiChapter` 四个 routes 字段。旧配置恢复时合并新默认值，无需清空数据。漫画 ID、目录章节 UUID、保存的网页章节 URL 保持兼容；API 地址可独立配置。

## 当前站点限制

2026-09-15 复测发现，网页目录/阅读端点会返回 HTTP 200，但目录为空、contentKey 为空，阅读标题变成与请求无关的“第10漫画”“第91漫画”等占位内容。同一网页接口偶尔又返回有效内容；改变 Accept、Referer 或附加查询参数未得到稳定修复，具体服务端触发条件未确认。

因此目录与阅读改用验证成功的官方 App API，不依赖网页 ccz/cct 或 contentKey。旧网页解密解析器和样本保留作兼容研究，但正常目录/阅读调用不会退回这些不稳定页面。其他旧 API 域名也出现空数据或404，未加入自动轮换。

本机原生 Java 实测：八角笼的帝王190话（首/末章86/174图）、蓝色监狱360话（75/17图）、忍者与极道46话（60/19图）。八角笼第1/2话 API 重复请求及首尾 WebP 图片均返回200。该结果不能保证所有网络、账号权限或漫画始终可用。

## 验证

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug
```

`app/src/test/resources/copy4000` 包含 2026-09-15 保存的公开接口样本，没有图片二进制或账号信息。测试覆盖搜索分类、旧网页解析，以及 App API 的100+90条目录分页、多分组、提前空页、重复页、标识校验、图片完整性、旧配置升级和实际 HTTP 请求头。

构建与解析测试通过不等于所有设备、网络环境中的站点访问都可用。设备端验收应重点确认非空阅读载荷、图片加载和目录可用性。
