# 拷贝漫画站源

内置 ID：`copy4000`；默认域名：`https://www.copy4000.com`。

已接入站源开关、全局搜索、站内搜索、分类分页、详情、目录、阅读解析、配置导入导出和图片 Referer。漫画主键为 `copy4000:{path_word}`，避免与其他站源混淆。

## 请求和解析

| 功能 | 路径／处理 |
|---|---|
| 搜索 | `/api/kb/web/searchci/comics`；platform=2，limit=12，offset=(page-1)*12，q_type 为空 |
| 分类字典 | `/filter`，动态读取题材 slug，保留大小写 |
| 分类列表 | `/comics`；limit=50，offset=(page-1)*50；读取 `.exemptComic-box` 的 list 属性 |
| 详情 | `/comic/{path_word}`，直接解析 HTML，目录按需另取 |
| 目录 | `/comicdetail/{path_word}/chapters`，用详情页 ccz 解密 results |
| 阅读 | `/comic/{path_word}/chapter/{id}`，用阅读页 cct 解密 contentKey |

筛选顺序：排序、题材、地区、状态。地区和状态的 `0` 为有效取值；全部选项不发送参数。分类 list 是实体编码的数据字面量，通过受限解析器读取，不执行网站 JavaScript。

目录与阅读密文均为前16字符 IV + 后续 Hex 密文，动态密钥按 UTF-8 编码，使用 AES/CBC/PKCS5Padding（AES 块上的 PKCS7 兼容填充）。章节与图片保留服务端数组顺序；目录遍历所有分组，不按不可靠的 count 截断；同章所有图片一次解析。

## 当前站点限制

采集时，在当前网络的原生 HTTP 和浏览器中，部分章节返回 HTTP 200 但 contentKey 为空。另一个抓取环境的有效阅读页可解出 86／96 张图片。解析器遇到空载荷、空图片或空目录时抛出明确错误，复用 App 原有错误／重试流程，不把它们缓存为成功章节。没有接入第三方抓取服务或自动切换到未经验证的接口。

网页自定义 `dnts: 3` 曾使已有190条章节的目录返回空数组，因此原生请求不照搬这个头。这不保证所有漫画目录始终可用。站点 total 与实际页数也可能不一致；App 原有分页去重和空页终止逻辑继续适用。

## 验证

```powershell
.\gradlew.bat :app:testDebugUnitTest --tests com.xxcomic.source.CopyMangaComicSourceTest :app:assembleDebug
```

`app/src/test/resources/copy4000` 包含 2026-09-15 保存的公开接口样本，没有图片二进制或账号信息。测试覆盖12条搜索分页、50条未渲染分类列表、65个题材、实体／引号转义、190条目录、两章完整图片顺序、错误响应、域名配置和分页参数。

构建与解析测试通过不等于所有设备、网络环境中的站点访问都可用。设备端验收应重点确认非空阅读载荷、图片加载和目录可用性。
