# 禁漫天堂静默验证与单章直读设计

## 目标

解决两个已确认问题：自动 Cloudflare 验证会展开网站页面并阻塞使用；禁漫天堂的单章漫画没有标准目录，当前被误报为“目录解析失败”。

本轮不改变列表、搜索、详情、阅读和缓存的数据模型，不新增依赖，也不扩大到其他站源的 HTML 解析规则。

## 已确认根因

`CloudflareWebViewSession` 在识别 challenge 后先隐藏 WebView，但固定等待 4 秒仍未完成时会调用 `showVerificationView(true)`。该调用把真实网站 WebView 扩成全屏并允许点击，因此网站页面和底部网址横幅会覆盖 App。

禁漫天堂目录解析只接受 `.episode` 内同时具有 `/photo/{id}`、匹配的 `data-album` 和 `.h2_series` 标题的链接。搜索“美丽新世界”得到的第一条 `album/1432767` 没有 `.episode`，但详情操作区存在有效的“开始阅读”链接 `/photo/1432767`。其正文页仍提供现有解析器需要的 `aid`、`scramble_id`、`cdnImgHost` 和 `page_arr`，所以它是可直接阅读的单章作品，不是目录或正文损坏。第二条 `album/1114754` 有标准 `.episode`，现有多章节解析正确。

## 验证模式

验证请求分为两种显式模式，请求创建时确定模式，不使用可被并发请求串改的全局标记。

### 自动静默模式

列表、搜索、分类、详情、目录和阅读请求只允许使用自动静默模式：

1. 先复用现有 Cookie、HTTP 和已验证浏览器上下文。
2. 命中 challenge 时，WebView 始终保持后台尺寸、透明且不可点击。
3. 验证开始时只发送一次“正在验证”轻提示，成功或失败各最多发送一次结果提示。
4. 整个请求的最长等待时间为 120 秒。
5. 120 秒内成功则保存 Cookie 和浏览器上下文，继续原请求。
6. 超时或失败则结束当前请求，不自动循环；现有页面显示可重试错误，用户重试时创建新请求。

后台验证不获取焦点、不拦截触摸、不改变当前页面。用户可以切换其他页面或站源。原页面的异步回调继续受现有页面代次和任务取消逻辑约束，离开页面后不得把旧结果强制显示到新页面。

### 设置页人工模式

只有用户主动点击“设置 -> 站点管理 -> 验证”时，请求才允许进入人工模式：

1. 仍先在后台自动尝试，避免每次手动验证都直接展示网站。
2. challenge 持续存在且确实无法自动完成时，才展示可交互 WebView。
3. 验证成功后立即隐藏 WebView、保存会话并显示“验证完成”。
4. 用户关闭或 120 秒超时后结束请求，不在后台无限重开。

自动业务请求永远不能升级为人工模式。这样网站页面和网址横幅不会在用户浏览 App 时自行出现。

## 单章目录兜底

`JmComicSource.parseChapters()` 保持分层解析：

1. 优先解析 `.episode` 内的标准章节。只要得到至少一章，直接返回现有结果。
2. 标准目录为空时，只检查详情操作区域 `.read-block` 内的链接。
3. 兜底链接必须同时满足：路径匹配 `/photo/{数字}`；可见文字包含“开始阅读”“開始閱讀”“继续阅读”“繼續閱讀”或“續看”；不是 `read_mode=read-by-page` 的重复入口。
4. 取第一个匹配链接，生成唯一章节，标题为“第1话”，URL 使用不带分页阅读参数的标准地址。
5. 标准目录和可信直读按钮都不存在时，继续返回空结果并沿用“暂无章节/目录加载失败”的现有处理。

兜底不得扫描全页所有 `/photo/` 链接，不得使用封面链接、时间线、推荐漫画或“猜你喜欢”区域，避免把其他漫画误识别为章节。

## 接口与数据流

保留 `BrowserSession.fetch(url)` 作为普通静默入口，并增加一个具有默认实现的显式人工验证入口。普通站源和测试中的 lambda 不需要改动；Cloudflare 会话覆盖人工入口，受保护站源的设置页验证方法才调用它。

`ComicModels.ComicDetail` 和 `ComicModels.Chapter` 不增加字段。单章作品通过现有单元素章节列表进入 `ensureChaptersThen()` 和阅读页，收藏、进度、续读、上一章/下一章边界继续复用现有逻辑。

## 错误与提示

- 自动验证开始：非阻塞蕾姆轻提示“禁漫天堂正在验证”。
- 自动验证完成：轻提示“禁漫天堂验证完成”。
- 自动验证失败或超时：结束当前加载并提供现有重试入口；不展示网站。
- 人工验证需要介入：仅在设置页主动验证流程中展示 WebView。
- 单章直读正文解析失败：按正文加载失败处理，不再误报目录失败。

日志保留 URL、HTTP 状态和验证阶段，不记录 Cookie、页面正文或验证码内容。

## 测试与验收

自动化测试覆盖：

- 自动请求遇到持续 challenge 时始终不产生展示 WebView 的动作。
- 自动和人工模式都在 120 秒超时。
- 只有人工模式允许 challenge 升级为可交互页面。
- 标准多章节样本仍解析出原章节数量和顺序。
- `album/1432767` 的详情结构解析为一个“第1话”，URL 为 `/photo/1432767`。
- 页面仅含推荐 `/photo/` 链接时仍返回空目录。
- 分页阅读入口不会生成重复章节。

真机验收：首次触发验证后立即切换页面和站源，当前操作应保持可用且不出现网站页面；验证完成后重新进入禁漫天堂可以加载数据；失败后点击重试可重新发起验证；“美丽新世界”第一条可直接进入阅读页，第二条仍显示完整目录。
