# 漫画屋站源退役设计

## 背景

内置站源 `mhua5`（漫画屋，`www.mhua5.com`）已经不可用。本次将它从应用的可用站源中移除，同时保留用户已有收藏、阅读历史、阅读进度和本地缓存。

本次不对接 `60ti.com` 或 `bbyin.com`，也不修改其他站源。

## 目标行为

- 站源管理、搜索筛选、全站搜索和健康检查不再出现漫画屋。
- 新导出的站源配置不再包含 `mhua5`。
- 导入旧配置时忽略 `mhua5`，不能通过配置重新启用。
- 不再保存或读取 `source.mhua5.enabled` 等活动站源偏好。
- 已有漫画屋收藏和历史继续显示，来源标记为“漫画屋（已下线）”。
- 已缓存的详情、章节目录、章节页面、封面和正文图片可以继续查看。
- 本地缺少所需数据或图片时立即失败或显示占位，不向漫画屋及其图片地址发起网络请求。
- 不把旧 `mhua5` 漫画错误地交给其他站源解析。

## 方案

采用“退役兼容适配器”方案。

保留 `Mhua5ComicSource` 类型和稳定的 `mhua5` ID，但把现有网络解析器缩减为无网络能力的兼容适配器。它只提供旧数据识别所需的 ID、名称和域名；所有需要远程数据的方法立即抛出明确的“站源已下线”错误，健康检查固定返回不可用。

相比在 `MainActivity` 的每个请求点分散空值判断，这个方案继续满足现有 `ComicSource` 契约，旧数据路由仍有确定目标，也不会意外回退到默认站源。相比只隐藏入口并保留解析器，它能从代码层保证不再访问旧站点。

## 活动站源清理

从 `MainActivity` 删除漫画屋的活动配置、启用状态和以下接入点：

- 站源管理卡片和开关；
- 搜索站源名称、ID 映射和下拉选项；
- 全站搜索启用列表；
- 图片 Referer 的活动站源配置判断；
- 配置导入、导出和本地 `source.configs` 编解码；
- `source.mhua5.enabled` 偏好的读写；
- 健康检查列表。

从 `SourceConfig` 删除 `mhua5(boolean)` 工厂。旧配置数组中的未知 `mhua5` 项由现有遍历逻辑自然忽略，不迁移为自定义站源。

`MainActivity` 仍持有一个退役适配器，仅供 `sourceNameForId`、`sourceForId` 和旧漫画 ID 前缀解析使用。它不加入任何可选或并发搜索列表。

## 旧数据与缓存

收藏、历史、阅读进度、摘要缓存、详情缓存和章节缓存保持原样，不做删除迁移。

详情和章节数据继续走现有缓存优先流程：

- 命中缓存时正常展示；后台刷新调用退役适配器后立即失败并沿用缓存。
- 未命中详情或章节缓存时，现有错误页面显示“漫画屋站源已下线”，允许用户返回。
- 已缓存章节页面仍可进入阅读器。

封面和正文图片加载增加一个最小的 `cacheOnly` 控制：

- 普通站源保持当前的内存缓存、磁盘缓存、网络回源顺序。
- `mhua5` 内容只检查内存和磁盘缓存；未命中时显示现有占位或黑色阅读页状态，不建立网络连接。
- 阅读器预加载同样遵守 `cacheOnly`，不能绕过前台加载限制。
- 收藏操作不再为退役站源触发封面预下载。

该控制通过现有加载函数的参数传递实现，不新增缓存层或第三方依赖。

## 错误处理

退役适配器统一返回可识别的 `IOException`，消息为“漫画屋站源已下线”。主动读取已有缓存不产生错误日志；只有用户请求了本地不存在的详情或章节时才沿用当前错误界面提示。

图片缓存未命中属于预期状态，直接显示占位，不记录为网络错误。

## 删除范围

删除原 `Mhua5ComicSource` 中的 HTTP、HTML 解析、正则表达式和路由代码。仓库中的旧站点探测脚本和抓取 HTML 也属于已退役实现，不再参与验证；实现阶段删除仅服务于 `mhua5` 的这些文件，避免继续维护无效站点资产。

保留可能同时用于爱看漫画或其他站源的联合探测脚本，除非确认文件只包含漫画屋逻辑。不会顺手清理无关工具。

## 测试与验收

先增加一个仓库级校验脚本并确认它在旧实现上失败，再做生产代码修改。校验覆盖：

- `mhua5` 不存在于活动站源 UI、搜索列表、配置导入导出和偏好读写中；
- `SourceConfig` 不再提供 `mhua5` 活动配置；
- 退役适配器仍保留稳定 ID，但不包含网络连接或解析代码；
- 旧数据仍能解析到退役适配器，不回退到默认站源；
- 封面、正文图片和阅读器预加载对退役内容启用缓存只读模式。

最终运行新增校验、现有相关交互/缓存校验、`git diff --check` 和 Android release 构建。手工验收时确认：站源入口消失；旧收藏/历史仍存在；缓存命中可查看；缓存未命中立即提示下线且无长时间等待。
