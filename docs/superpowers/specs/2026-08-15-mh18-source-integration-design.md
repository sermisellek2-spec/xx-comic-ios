# 18漫画站源接入设计

## 目标

将 `https://18mh.org` 作为新的内置站源“18漫画”接入 XX Comic。站点需要 VPN 才能访问；其页面、接口、章节和图片编码结构按现有“G社漫画”处理，但两个站源使用独立实现和独立数据标识。

## 实现方式

- 新增 `SourceConfig.mh18(boolean)`，固定 ID 为 `mh18`、名称为“18漫画”、域名和入口为 `18mh.org` / `https://18mh.org`。
- 新增独立的 `Mh18ComicSource`，以当前 `GmhComicSource` 为基线复制实现，仅替换站源 ID、默认配置、站源名称和主站入口。
- 列表、搜索、动态分类、详情、章节 API、图片解密和图片线路规则保持与 G社漫画一致。
- 不重构或修改现有 `GmhComicSource`，避免新站源影响现有 `gmh:*` 书架、缓存和阅读记录。

## App 接入

- “18漫画”默认开启，并加入设置页站源管理、启用/关闭、可用性检测和站源配置导入导出。
- 加入发现页单站列表、单站搜索、全站搜索和筛选流程。
- 使用 `mh18:` 作为漫画 ID 前缀，使详情缓存、书架收藏、章节记录和阅读进度与 G社漫画完全隔离。
- 图片请求对 `18mh.org` 使用新站源 Referer；共享图片线路沿用 G社的 CDN 规则，阅读正文优先使用章节页 Referer。

## 错误处理

- VPN 未连接、域名返回 403、连接超时或解析失败时，沿用 App 当前的加载失败轻提示，不循环重试。
- 解析异常使用“18漫画”名称，便于错误日志区分两个同构站源。
- 不增加自动换域、代理配置或后台轮询。

## 发布

- 按用户要求不运行测试套件；Release 打包属于发布必要步骤，仍需成功生成 APK。
- 版本升级为 `1.0.23 (23)`，同步现有版本契约中的版本号。
- 精确暂存本次源码、规格、计划和版本文件，保留工作区已有构建产物不处理。
- 提交并推送 `master` 后，将 APK 上传到 COS `apk/xx-comic/xx-comic.bin`，同步服务器备用 APK 和更新元数据。
- 发布后核对本地 APK、COS 对象和服务器备用包的 SHA-256 一致。
