# MainActivity 稳定性修复设计

## 目标

在不引入新依赖、不迁移 Compose、不重构无关代码的前提下，一次完成导航、异步请求、缓存一致性、阅读器内存和低成本交互共 13 项修复。

## 实施边界

- 主要修改 `app/src/main/java/com/xxcomic/MainActivity.java`。
- 键盘行为修改 `app/src/main/AndroidManifest.xml`。
- 使用现有 `tools/check-*.js` 源码契约测试模式补充回归检查。
- 不处理 TalkBack、平板布局、全面颜色调整、Compose、自定义站源协议和大型自动化测试。
- 不新增依赖，不顺手整理乱码注释或无关代码。

## 第一批：异步导航与请求隔离

### 加载页返回

`showPageLoading()` 保存明确的返回动作。首次详情加载保存来源页面恢复动作；章节目录加载保存返回详情动作。`navigateBack()` 先使加载 generation 失效并取消当前页面任务，再执行该动作，不再通过 `activeDetailId` 推测目标。

### 阅读请求令牌

增加 `readerGeneration`，由 `enterScreen()` 递增。章节请求捕获 generation、漫画 ID 和章节 URL；成功与失败回调仅在三者仍匹配、阅读器仍可见时提交。主动取消和过期回调静默丢弃。

### 空章节与返回入口

空章节和目录异常都先恢复详情页，再显示带重试动作的提示。全站搜索、详情、历史和阅读器工具栏统一调用 `navigateBack()`，与系统返回和边缘手势保持一致。

### 分类请求隔离

增加 `categoryGeneration`。分类请求捕获 generation 和站源 ID，回调在修改 `sourceCategories` 前同时校验两者。

## 第二批：缓存、线程归属与数据语义

### 会话内后台刷新

缓存详情立即展示。每本漫画在本进程首次打开时触发一次后台详情和章节目录刷新；使用两个仅主线程访问的集合记录已刷新和刷新中漫画，禁止同一本并发刷新。刷新失败继续使用缓存，且本次进程不循环重试；用户显式点击重试不受该限制。刷新成功后更新缓存，当前仍显示该漫画时刷新界面。

### 主线程拥有共享集合

`summaries`、`details`、`chapters` 的增删清操作统一在主线程执行。网络线程只获取结果并投递 DTO。主线程生成三个不可变快照，`miscIo` 按 FIFO 顺序完成 JSON 序列化和 SharedPreferences 写入。移除会与异步旧快照发生倒序覆盖的同步持久化路径，不使用 `ConcurrentHashMap`。

### 阅读历史与收藏

仅在获得有效且图片非空的章节页，并通过阅读令牌校验后，写入章节进度和最后阅读时间。删除或取消收藏只修改收藏列表和收藏时间，不删除阅读历史、章节位置和最后阅读时间；同名收藏替换遵循相同语义。

## 第三批：阅读器内存

使用平台 `ListView + BaseAdapter` 替换整章 `ScrollView + LinearLayout`。Adapter 仅持有 URL，不持有整章 Bitmap；复用 `ImageView` 时清空旧图并设置 URL tag。

阅读图片使用独立加载路径：继续复用磁盘缓存，但不读写封面 `imageMemoryCache`；按屏幕宽度使用 `BitmapFactory.Options` 计算采样率；主线程回调同时校验 URL tag 和阅读 generation，避免串图及旧阅读请求覆盖。

阅读位置继续使用现有 0–10000 存储值，以首个可见条目和条目内偏移换算比例；滚动时延迟保存，恢复时使用 `setSelectionFromTop()`。旧版位置允许近似恢复，不迁移或清除用户数据。

## 第四批：低成本交互

- 分页追加失败立即替换 loading footer 为“加载失败，点击重试”；保留 `searchHasMore`，恢复网络后重试同一页。
- 点击当前底部 Tab 直接返回，不调用 `showTab()`。
- 隐藏“添加站源”和自定义站源卡片；保留配置、导入导出和已有数据。
- Manifest 使用 `adjustResize`，删除 `onCreate()` 中的 `SOFT_INPUT_ADJUST_NOTHING`。

## 测试与验收

每批遵循测试先行：先新增或扩展会失败的 `tools/check-*.js` 契约检查，确认失败原因对应缺失行为，再做最小实现并运行检查。最终运行全部相关脚本和 `gradlew.bat :app:assembleDebug`。

真机验收覆盖：加载页三种返回方式、快速切源、旧阅读响应、空目录与离线重试、服务端新增章节、并发搜索与详情、删除收藏后历史保留、30–50 张长图快速滚动和切章、分页断网恢复、重复点击 Tab、键盘避让。
