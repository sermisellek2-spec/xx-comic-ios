# 催漫画站源接入设计

## 目标

将 `https://www.cuimh.com` 作为第 13 个内置站源接入 XX Comic，支持漫画列表、分页、动态分类、详情、章节目录和正文阅读。站点的关键词搜索需要图形验证码，因此 App 不调用搜索接口。

## 范围

- 新增内置站源 `cuimh`，默认开启并参与站源管理、导入导出和可用性检测。
- 分类页动态解析“分类、标签、类型、品质、地区、版权、进度”，其中“标签”在 App 中显示为“题材”，“进度”显示为“状态”。
- 不展示“资费”。同一分类组内按显示名称保留第一个选项，去掉重复项。
- 多个筛选值按站点路径顺序拼接，分页追加 `/page/{page}`。
- 详情页解析标题、封面、作者、类别、状态、简介和最新章节。
- 章节目录从详情 HTML 中异步解析，保持站点顺序并按章节 URL 去重。
- 正文从页面 `params` 密文中解析。Base64 解码后，前 16 字节作为 IV，剩余字节使用固定 UTF-8 密钥和 `AES/CBC/PKCS5Padding` 解密，读取 JSON 的 `images` 数组。
- 正文图片请求使用具体章节页 URL 作为 Referer；封面沿用站点或 CDN 默认规则。

## 搜索行为

`ComicSource` 增加默认返回 `true` 的 `supportsSearch()` 能力。催漫画返回 `false`：

- 单站模式提交关键词时显示轻提示“催漫画暂不支持搜索”，不发出搜索请求。
- 全站搜索只调度支持搜索的已开启站源，因此自动跳过催漫画。
- `CuimhComicSource.search()` 仍抛出明确 `IOException`，防止其他调用方把“不支持”误判成空结果。

## 错误处理

- 分类结构、详情标题、章节目录、密文或图片数组缺失时抛出带站源名称的 `IOException`。
- 解密校验 JSON 中的 `host` 必须与 `www.cuimh.com` 一致，避免错误密钥产生的垃圾数据进入缓存。
- HTML 或加密规则变化时只影响独立的 `CuimhComicSource`，不改动其他站源解析器。

## 验证与发布

- 单元测试覆盖列表、筛选组合、详情、章节和 AES 图片解密。
- 运行现有 release 单元测试、源码契约检查和 release 构建。
- 版本升级为 `1.0.21 (21)`，验证 APK 包名、版本、签名和 SHA-256。
- 精确暂存本次文件，推送 `master`，上传 COS `apk/xx-comic/xx-comic.bin`，同步服务器备用包和更新元数据，再回下载校验。
