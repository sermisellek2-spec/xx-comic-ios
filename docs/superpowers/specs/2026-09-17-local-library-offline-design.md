# 本地书架、离线下载与文件源设计

日期：2026-09-17。基线：`master@9cb04f4`，2.0.21 / 221。
工作分支：`codex/local-library-offline`。本文是已确认需求及实施默认规则，不代表功能已经实现。

## 1. 已确认的产品范围

1. 文件和下载内容只存在手机本机，不建设账号、服务器存储或云同步。
2. 第一阶段完整交付图片文件夹、ZIP/CBZ 导入、本地目录和阅读；EPUB、MOBI、AZW 依次扩展。
3. 下载范围支持单章、选中多章、全部章节。
4. 平铺图片作为一章；一级子文件夹作为章节；ZIP/CBZ 同样处理。
5. 书架页顶部为“我的书架 | 本地书架”。选中项大字号、主文字色，未选中项小字号、灰色，约 200ms 柔和切换。深色使用相应主题颜色。
6. 本地书架右上角提供导入、下载中心；底部保持书架、发现、设置。
7. 导入复制到 App 专用目录，不修改用户原文件。卸载或清除 App 数据会移除副本。
8. 在线与下载内容关联：同站源同作品合并，共享阅读进度；已下载章节优先本地，未下载章节在线读取。
9. 删除本地漫画删除对应副本或下载文件；支持单独删除已下载章节；保留在线收藏、历史和进度。
10. 缓存清理不删除导入和离线下载。存储管理支持集中查看与批量清理。
11. 默认仅 Wi-Fi、1 个章节任务、每章至多 2 张图片并发；切页、后台、锁屏继续；断网等待，手动暂停不自动恢复。
12. 任务和已完成页持久化，系统终止后下次打开可恢复。验证失效暂停相应站源任务，用户去站源管理验证；不自动弹网页。
13. 电子书范围包括图片漫画、文字和图文混排，采用各自合适的阅读排版。
14. 直接文件源先完整下载、校验、解析再阅读，不承诺远程压缩包流式阅读。
15. Gemini 按阶段实现、自检和提交阶段报告；Codex 代码验收、用户真机验收均通过后，由用户明确启动下一阶段。

## 2. 本次确定的实施默认值

以下用于消除实现歧义；与已确认功能同样写入验收标准。

- 保留现有 Java/native Android UI、minSdk 23、compileSdk/targetSdk 34；不整体重写 MainActivity，不切 Compose/Kotlin，不升级构建体系。
- 第一阶段图片格式为 Android 能解码的 JPEG/PNG/WebP，以及 GIF 静态首帧；不承诺动画播放。通过文件签名和实际解码检测，不能仅看后缀。
- 单文件多选导入 + 系统文件夹选择。不做全盘扫描、不申请所有文件管理权限；系统分享导入不纳入第一阶段。
- 一本 ZIP/CBZ 作为一本作品。连续单一外层目录先去掉包装层；根目录图片和章节并存时根图片构成“未分章”，不遗漏图片。更深层路径合并进所属一级章节，以完整相对路径自然排序。
- 章节和图片使用稳定自然排序，保证 1、2、10；同序号以完整路径作稳定次序。不依据网站目录显示正逆序改变实际章节身份。
- 忽略目录占位、`__MACOSX`、`.DS_Store` 等元数据，不忽略正常的非 ASCII 路径。ZIP 中文文件名先按 UTF-8 读取，编码不兼容再明确尝试 GB18030；碰到加密/不支持的压缩方式报具体格式错误。
- 首张有效页面为封面，提取封面不得从正文删除该页；封面失败使用现有 `rem_no_image`（蕾姆“没有封面哦～”）。标题默认去掉扩展名的文件名或文件夹名；名称不可用时生成持久且不冲突的“未命名漫画 N”。本地详情提供重命名，只改 App 展示名称，不改原文件/指纹/进度键；重导同一文件保留自定义名称。第一阶段不加入分组移动、自选封面或其他元数据编辑。
- 后续 EPUB/MOBI/AZW 优先使用有效的书内标题和明确封面资源；缺失时依次回退文件名、未命名标题，以及首张适合做封面的内容图、蕾姆默认图。没有封面/书名不等于不可阅读，完全没有可读正文才拒绝入库。文字书无图片是有效文档。
- 精确文件重复导入不新增作品。同名不同内容作为不同作品；不因标题相同合并本地和在线作品。
- 第一阶段只显示已支持的功能入口。下载中心在第二阶段接通，第一阶段不放一个不可用按钮。
- 下载按章节完整性标记完成；部分成功保留已完成页，失败章节可重试，不显示“全部已下载”。完成章节可以立即读，不必等整本下载结束。
- 从本地书架点“继续阅读”优先恢复记录；记录指向未下载章节时，断网展示“这一章还没下载”及“查看已下载章节”，不悄悄跳到另一章。
- 删除时保留极小的作品身份/定位记录用于重新导入续读，不保留封面或正文副本。记录仍可通过现有历史管理单独删除。

## 3. 页面及视觉规范

### 页面地图

```text
底部：书架 / 发现 / 设置
书架
 ├─ 我的书架（收藏、续读、更新星标按原逻辑）
 └─ 本地书架
     ├─ 导入抽屉 → 系统选择文件/文件夹 → 后台复制、解析
     ├─ 本地作品详情 → 目录 → 现有漫画阅读页 / 电子书阅读正文
     └─ 下载中心 → 单本任务/章节详情
在线详情 → 下载章节抽屉 → 下载中心 → 本地书架
设置 → 本地与下载
 ├─ 下载偏好（仅 Wi-Fi）
 └─ 存储管理（导入文件 / 离线章节 / 可清理临时文件）
```

新增独立页面：本地作品详情、下载中心、单本下载任务详情、存储管理。本地书架是原书架的子视图；导入、下载章节选择、删除确认是抽屉或弹框。电子书阶段增加正文渲染器，复用阅读外壳，不再新增一级导航。

### 书架

- 两个标题基线对齐。初始规格：选中 24sp/主题 `TEXT`，未选中 16sp/`TEXT3`，最终在第一阶段截图中校准。
- 过渡约 200ms，用预留宽度和固定标题行高度避免内容跳动；连续点击取消旧动画、落到最后选择。减少动画/系统动画关闭时立即切换。
- 两页各保存滚动位置；切换不重复导入、不触发全书架联网请求、不自动切页。
- 右侧导入/下载采用紧凑图标按钮，至少 48dp 点击区域和无障碍描述。窄屏、大字体时次要操作收进“更多”，不挤压标题。
- 本地书卡沿用当前封面网格、间距、圆角，无阅读进度条。可用简短小字标记 ZIP、文件夹、已下载章节数；进度文字沿用“上次看到”。
- 首版全部展示本地作品；不提前增加空的“电子书”筛选。下载进度集中在下载中心。

### 本地详情与阅读

- 复用当前详情的封面、正文、阅读按钮、目录排版；纯导入隐藏站源切换、联网更新检查及在线收藏操作。
- 在线下载作品保留来源关联，提供“查看在线详情”；本地详情自身无需访问站点才能打开。
- 目录保持现有样式及 76% 宽度；下载选择用独立底部抽屉，避免把目录交互改成多选。
- 图片阅读保留条漫/单页、左/右手、触碰/按钮/手势、沉浸动画、上下章、进度条、右下角信息。
- 文字阅读复用顶底控制层与主题，正文有独立的字号/行距/位置锚点。图片专属设置在文字正文不展示。

### 下载与删除状态

- 下载中心按正在处理/已完成查看，作品聚合后可展开到章节；展示页数进度、已下载大小，大小未知不编造百分比。
- 有可读章节就可进入本地详情；零完成章的作品保留在下载中心，不放空书进本地网格。
- 单章、多章、全部：选择基于稳定 chapterId，不基于显示位置；已完成章不重复选择，全部指本次获取的目录快照，不自动订阅新增章节。
- 删除确认使用现有蕾姆主题，显示可释放大小和“保留收藏与阅读记录”。先停任务再删文件；删除失败报告未删除项，不能虚报空间已释放。
- 空/加载/错误沿用 `rem_empty`、`rem_loading`、`rem_error`，短文案。复制/下载/解析均不阻塞其他页面。
- 浅深色都使用 `UIHelpers` 颜色与现有控件，不硬编码白底黑字，不新增明显不同的 Material 风格页面。

## 4. 架构边界：复用阅读入口，按来源提供内容

```text
系统文件选择 ──→ 本地导入 ───────────────────┐
现有站源章节 ──→ 图片下载 + 必要解码 ────────┼→ 持久文件 + 内容索引 → 阅读内容解析入口
未来文件站源 ──→ 整文件下载 → 格式解析 ──────┘                        ├→ 图片阅读器
现有在线站源 ──→ 现有章节及图片加载（本地优先判定后）─────────────────┘ / 电子书正文
```

采用一个小型本地内容模块和一个下载模块。第一阶段仅建立图片资源接口；EPUB 到相应阶段再增加 publication/spine/locator，不能提前造空格式插件体系。下载器拥有网络传输、任务恢复；格式解析器只处理已存在的本地文件。站源负责元数据和解析下载资源，不自行调度下载。

当前关键文件：

- `MainActivity.java`：路由、书架、详情、阅读控制层、图片请求/解码、进度和缓存管理均在此。只插入明确入口，提取必要图片处理边界，不能全文件重构。
- `source/ComicSource.java`、`ComicModels.java`：在线图片接口继续兼容，不把所有站源强制改成新格式。
- `reader/PagedReaderView.java`、`ReaderPosition.java`、`ReaderNavigation.java`：保留图片阅读交互和定位行为。
- `source/ManwaImageDecoder.java`、`MainActivity.restoreJmReaderImage()`：下载和离线读必须保持相同处理语义。
- 目前缓存位于 `getCacheDir()`，元数据/进度大量使用 SharedPreferences；持久下载绝不能冒充图片缓存。

建议新增职责（按阶段创建，不一次创建空类）：

| 模块 | 责任 |
| --- | --- |
| `local/LocalLibraryStore` | 本地书、章节、页面索引和事务 |
| `local/LocalImporter`、`ArchiveIndex` | SAF 复制、身份计算、图片/ZIP 索引 |
| `local/LocalContentResolver` | 获取本地页面流、按需解压和完整性状态 |
| `local/LocalLibraryView`、`LocalDetailView` | 书架/本地详情与现有路由连接 |
| `local/LocalStorageManager` | 统计、受限目录删除、临时文件回收 |
| `download/DownloadStore`、`DownloadCoordinator` | 持久队列、并发、重试、取消、恢复 |
| `download/DownloadService` | 用户发起下载的前台服务、通知和生命周期 |
| `download/SourceImageFetcher` | 与现有在线路径共享请求和图片处理语义 |
| `download/DownloadCenterView`、`DownloadSelectionSheet` | 队列与章节选择界面 |
| `ebook/` | EPUB 和后续格式的文档模型、格式适配、文字渲染 |

优先 Android SAF、Java ZipFile、MessageDigest、SQLite 和现有依赖。大型任务索引不塞 SharedPreferences；采用 Android 自带 SQLite，避免仅为 CRUD 引入 ORM。需要第三方格式库时先做兼容/许可/包体评估，在该阶段报告确定版本和选择理由。

## 5. 文件、身份与阅读进度

- 根目录采用 App 私有、排除系统自动备份的位置，例如 `getNoBackupFilesDir()/library/`；数据库和任务日志同样排除备份。不改变原有收藏/设置的备份政策。
- 根下分 `imports/`、`downloads/`、`staging/`、`derived/`；原始导入副本和已完成章节持久保存，衍生缩略图/解压页可重建。
- 原始 Content URI 只用于导入期读取，不保存为长期阅读依赖；文件选择器返回未知长度也必须流式复制并检查剩余空间。
- ZIP 原文件保留，按需提取页面到有上限的衍生缓存；不一次性全量解压到内存。图片文件夹复制结构，只导入支持的图像。
- localBookId：应用生成的稳定 ID；importFingerprint：文件 SHA-256，文件夹为自然排序的相对路径与各图片内容哈希构成的清单哈希。不因修改时间、显示名改变丢失进度。
- 下载作品身份 `(sourceId, comicId)`；下载章节身份 `(sourceId, comicId, chapterId)`。URL 可更新，不能用会过期的签名 URL 作唯一身份。
- 对在线下载作品，progressKey 沿用原在线作品的真实键；不新增与原键竞争的两份进度。跨站同名不自动同步，本地导入不按名称关联在线作品。
- 图片定位记录稳定章节身份、页身份/索引、页内 offset 与完成状态；先按身份恢复，再做边界裁剪。保留旧数据读取能力，只做增量适配。
- 文本定位使用文档资源/spine + 字符/DOM 锚点（采用阅读内核支持的 locator）；不能用当前分页页码作永久位置，字号变化后仍可恢复。
- 删除后的导入指纹映射及定位元数据保留，但内容索引不能指向已经删除的文件。删除历史时同步移除这部分续读记录。

## 6. 完整性、安全与恢复

- 文件系统与数据库不是单一事务：先写 staging、记录状态、校验，再同盘重命名正式目录，最后提交可读索引。启动只扫描未完成任务与中间状态，修复或回收孤儿，不重扫全部文件。
- 删除先持久化 deleting 状态并取消对应任务、作废任务代次，等待文件句柄释放，再清理受限路径和索引。晚到回调不能重建已删除作品；失败保留可重试记录。
- 根路径 canonical 校验，拒绝 `../`、绝对路径、盘符路径、符号链接越界、重复规范化 entry；拒绝路径穿越。不递归解压嵌套压缩包。
- 初始解析保护：最多 50,000 个条目，单条实际输出上限 128MiB，总解压声明/实际预算上限 20GiB，同时受设备实际可用空间约束；超限清晰提示，不默默截断。页图按现有像素/内存预算采样，保护需覆盖头部伪造与实际写出字节。
- 复制或下载前预留至少 256MiB 空间并动态复核；不能保证一定够时显示未知大小，磁盘满时立即暂停，不损坏已完成内容。
- 密码压缩包首版不支持密码输入；损坏、不支持方法、无图片分开提示。正文局部坏页可重试/跳过并标识，不能当成正常已下载。
- EPUB HTML 不加载网络脚本、任意外链资源或远程页面；脚本默认关闭、导航限定到本书资源，无不必要 JS bridge。

## 7. 下载执行规则

- 持久状态：queued、resolving、downloading、verifying、completed、paused_user、waiting_network、waiting_verification、failed、cancelled、deleting。
- 默认 1 个章节处理任务、每章至多 2 张图；前台阅读优先，下载使用独立有界队列，不与全站搜索争抢全部线程。
- 前台服务从用户可见的下载动作启动，适配 API 23–34 的通知渠道、POST_NOTIFICATIONS、FOREGROUND_SERVICE 和 Android 14 dataSync 类型权限。拒绝通知权限时明确状态，不以权限拒绝导致崩溃。
- 不承诺绕过 Android 强行停止、省电限制或系统回收；下次启动从持久状态恢复，用户暂停的任务仍保持暂停。锁屏后台持续能力以真机证据验收。
- 网络瞬态错误最多自动重试 3 次，退避 2s/5s/15s；429 优先合理的 Retry-After 并暂停相应站源；无效认证/403/验证异常不无限重试、不改成关闭 TLS 验证。
- 沿用 JM/18mh 各自凭证，不修改验证实现、不写共享认证池。一个站源等待验证不阻塞其他站源任务；用户主动验证成功后恢复未被手动暂停的相关任务。
- 图片按页提交，只有校验完的页计入完成；中断只补缺页。字节级续传仅在服务器提供一致的 ETag/Last-Modified 及合法 206/Content-Range 时使用；返回 200 或实体变化时安全重下该页/文件，不能 append 出损坏文件。
- 漫蛙：保留当前字节解码语义；JM：保存离线还原所需原始图片身份及 scramble 参数，不得因为改成本地路径丢失还原信息，也不能二次还原。可保存已解码但仍待排列还原的字节，页记录明确 transformation 标记；不重新有损压缩。
- 下载完整章节后断网、清理普通缓存、禁用站源，仍能打开已下载详情、目录和图片；不依赖凭证重新请求网页。
- 取消任务保留已经正式提交的章节，删除未完成任务临时内容；“删除本地漫画”才删除全部对应内容，弹框明确区别。

## 8. 后续文件格式与文件站源

| 范围 | 交付方式 |
| --- | --- |
| ZIP/CBZ、图片文件夹 | 第一阶段原生能力完成，PNG/JPEG/WebP/GIF 首帧 |
| EPUB 图片漫画 | 按 OPF spine/manifest 与导航顺序，不能文件名排序；固定版式按页排版，不随意丢弃 XHTML 上文字 |
| EPUB 文字/混排 | 独立文本渲染、字号行距、图文、目录、稳定位置；共用外层主题控件 |
| MOBI、AZW、AZW3 | 先样本和库可行性验证，再按可证明的实际变体交付；识别受保护/不支持变体，不承诺所有 Kindle 文件 |
| 直接文件站源 | 站源返回可刷新下载资源，统一队列下载完整文件，然后调用同一导入/解析路径 |

EPUB 声明为固定版式但包含图文/复杂布局的，必须正确渲染或明确暂不支持；不能抽几张图就宣称支持。MOBI/AZW 缺少可维护的 Android 本地解析方案时报告证据和替代方案，不能引入在线转换服务。PDF、RAR/CBR、7Z、KFX、自动备份/导出、全盘自动扫描不在当前交付范围。

文件源以可选能力接入：提供作品/卷身份、格式、长度（可未知）、下载资源解析与刷新；下载器拥有传输、凭证使用和恢复逻辑，站源不持有全局下载实现。具体文件站点尚未提供，第六阶段用可控本地 HTTP 样例证明接口闭环，不宣称某真实站点已对接。
