# 阶段 4：EPUB 文字与图文混排 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans when available. 仅执行本阶段，完成报告后停止。

**Goal:** 本地 EPUB 文字书与图文混排可阅读，提供字号、行距、目录和排版变化后的稳定续读。

**Architecture:** 复用阶段 3 Publication、资源解析与本地身份；增加可重排正文渲染器。图片与文字使用不同位置类型，共用阅读外壳，避免把文本渲染成图片或复制所有阅读控制代码。

**Tech Stack:** Java、受限本地 WebView 或经证据评估的维护中 EPUB 内核；Android 原生主题、SQLite。

**Spec:** `docs/superpowers/specs/2026-09-17-local-library-offline-design.md`

## Global Constraints

- 阶段 3 已通过双重验收。不能把文本页码写入图片页索引、不能沿用页面像素位置作为唯一定位。
- 不联网转换，不运行书内脚本；复杂 HTML/CSS 必须报告实际支持边界。
- 文字阅读器设置与漫画设置分开存值，改文字字号不能改变图片翻页/单双页偏好。

## Task 1：选定正文内核并证明稳定位置

**Files:** 新增 `ebook/TextLocator.java`、`TextReaderView.java`、对应测试；必要依赖仅修改 app/build.gradle 并记录理由。

**Interfaces:** TextLocator 保存 publication 身份、spine item、规范化资源 href 和内容锚点/偏移；TextReaderView 提供打开 Publication、获取/恢复 locator、更新字号行距与主题、释放资源。用回调向现有外层发送当前位置和章节边界。

- [ ] 先用包含长段落、图片、嵌套标题、内链/脚注和中文字体的自制 EPUB 验证原生方案；若不足，比较可维护 Android 内核的 API23/Java17/AGP7.4 兼容、许可与包体后选型，记录证据。
- [ ] 先写定位测试：不同字号/宽度下回到同段附近，字节偏移不切断 UTF-8，标题内链不误认为外部 URL。
- [ ] 实现 locator 持久化和恢复，不使用当前视口页码作为长期数据；索引变化失配时回到同 spine 中最近合法位置并轻提示。
- [ ] 用设备测两个屏幕宽度、三档字体/行距，记录实际误差和可接受边界；失败不能被“全文百分比一致”掩盖。
- [ ] 提交正文边界和定位测试。

## Task 2：图文排版和现有阅读外壳接合

**Files:** 扩展 ebook 正文实现，必要 `TextReaderSettingsSheet.java`；修改 MainActivity 阅读路由与读取设置的局部适配。

- [ ] 保留上章/本章进度/下章、目录/详情/设置及沉浸外壳，文字正文默认滚动，也支持内核证明可行的分页；不对外承诺未经验证的排版模式。
- [ ] 文字选择/正文纵向滚动优先，横向翻页只在明确分页模式启用。左/右手只改变翻页方向映射，不能反转书的逻辑顺序。
- [ ] 设置提供字体大小、行距与主题；字体从系统可用字体选择，不静默下载在线字体。隐藏只适合图片的缩放/条漫设置。
- [ ] 本章进度依据当前 spine 的可读位置，时间/电量仍取系统状态；目录支持章节层级和内部锚点。
- [ ] 图文加载来自本书资源，有坏图时轻提示但文本可继续；外链需要用户主动触发外部打开，书内 JS 和主动网络请求保持禁用。
- [ ] 浅深色、大字体、长章节、图文交错、重新启动、返回本地书架与历史续读检查；再执行旧漫画完整阅读回归并提交。

## 人工验收与停点

1. 导入纯文字 EPUB、图文 EPUB，飞行模式可读，目录跳转准确。
2. 修改字号/行距、旋转屏幕后仍停留在原段附近；杀进程重开可以恢复。
3. 图像比例不变、脚注/内链行为明确、文本选择不误触下一章。
4. 切回 ZIP/CBZ 或在线漫画，其左右手、翻页方式、缩放和沉浸均不变。

- [ ] 写 `local-library-stage-4.md`，标明内核版本、支持的 EPUB 行为与限制；交验收包后停止。
