# 批量本地导入阶段报告

日期：2026-09-18
分支：`codex/local-batch-import`
基线：`master@d403daf`

## 本轮完成

- 新增无 Android 依赖的批量导入规划器：按来源作品或规范化文件名形成候选合集。
- 支持 `第01卷`、`Vol.2`、`v3` 和尾部数字卷号自然排序；显式来源顺序优先。
- 同一批次内按内容指纹去重；本地文件没有站源身份时仍保留候选确认标记。
- 多选本地文件改为后台任务，最多两个文件并行；书架保留蕾姆进度横幅，可查看或取消，不再被模态导入框阻塞。
- 批量 EPUB/MOBI 走结构快速模式，导入时跳过逐页图片解码，阅读时沿用现有按需解码和错误处理。
- 同一规范化标题的同格式文件通过现有追加入口归并为一本本地书，并按卷名作为目录章节标题。
- 单文件导入、文件夹导入和在线下载路径未改行为。

## 尚未完成

- SQLite `series/volume` 独立表和旧数据迁移尚未实现；当前批量归并复用旧 Book 的追加章节模型。
- EPUB 与 MOBI 混合合集、合集级单卷删除/调序、导入确认抽屉和下载中心合集聚合留在后续任务。
- 当前批量模式仍会后台复制并计算完整哈希，只是不再阻塞 UI 和跳过导入时逐页解码；真正的轻量元数据预扫描需下一步接入。
- 未运行真机验证；本轮只运行 JVM 测试。

## 验收重点

1. 多选 32 个同名 EPUB，确认只形成一个本地书架条目并逐卷出现。
2. 多选 300+ 个不同漫画文件，切换到发现/设置，确认后台整理不阻塞。
3. 插入坏文件，确认其他卷继续处理，失败文件有明确记录。
4. 重复选择同一文件，确认不新增重复章节。
