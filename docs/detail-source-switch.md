# 详情页站源切换

进入详情页后，页面正常显示，同时后台用完整漫画名搜索已开启且支持搜索的站源。每站只请求搜索第一页，取第一个名称完全匹配的结果（仅去除首尾空白，区分大小写、不合并副标题）。当前站源不重复搜索。

换源入口放在标题右侧，显示“当前站源 ⇄”。点击打开底部半屏抽屉，列表显示封面、漫画名、站源名，当前站源带蓝色勾选。抽屉可上拉展开、下拉收起或关闭；展开后列表可滚动。后台新匹配项实时补入，已创建的封面视图复用；站源按设置中的顺序排列，初始站源置顶。点击选项后关闭抽屉并显示“切换中”，目标详情成功加载后才切换，失败保留原页并用蕾姆轻提示。封面、目录、阅读、收藏和历史使用目标站的数据，不迁移其他站的阅读进度。

后台搜索与发现页搜索状态、详情请求线程隔离，最多三路并发，每个请求开始执行后有十秒超时。不支持搜索、无精确匹配、请求失败或需要验证的站源不加入列表；不会主动开启验证网页。点击换源时若凭证失效，轻提示前往站源管理验证。详情切换二十秒超时，可再次点击重试。

缓存最近一个漫画名的匹配结果五分钟；同一详情重绘或换源沿用正在执行的搜索。离开详情取消未完成请求并屏蔽迟到回调，已完成结果可在短时返回时复用。站源启用列表或顺序变化会重新匹配。收藏状态与更新星标仍按目标漫画原有逻辑处理。

边界：完全同名仍可能是不同版本；搜索第一页没有匹配项不代表站点没有这部漫画。

验证命令：

```powershell
./gradlew.bat :app:testDebugUnitTest :app:assembleDebug
```

设备验收关注：右上角换源入口、抽屉上拉展开/下拉收起、列表滚动、结果分批显示、快速连续换源、失败保留原页、返回发现页后无旧请求跳转、从阅读页进入详情再返回时阅读位置不变，以及各站自己的收藏/进度。
