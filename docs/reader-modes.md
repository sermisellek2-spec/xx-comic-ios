# 阅读模式

入口：设置 → 阅读模式。阅读页控制栏的“阅读设置”也进入同一页面，系统返回键回到原章节。

## 操作约定

「设置 → 阅读模式」新增「沉浸模式」：默认普通模式；选择完全沉浸后，右下角的章节、页码、时间和电量整组隐藏且不占位。控制栏仍按原方式呼出，设置独立保存，适用于条漫、单页及墨水屏显示。返回阅读页保留章节和位置。

| 设置 | 行为 |
| --- | --- |
| 条漫 | 连续上下滚动；触碰、按钮或横向滑动切换章节 |
| 单页（日漫） | 一页一图，等比完整显示；翻到首尾后继续操作才切换章节 |
| 左手 | 左侧点击、向右滑动前进 |
| 右手 | 右侧点击、向左滑动前进 |
| 按钮 | 始终按“上一页 / 下一页”或“上一章 / 下一章”的文字操作 |
| 普通模式 | 常规彩色展示，暗色背景，适配手机与平板屏幕（默认） |
| 墨水屏模式 | 黑白高对比度优化，纯色背景无过渡闪烁，适配电子墨水屏设备 |

单页支持双击和双指缩放，放大后拖动图片不会翻页。左右手只改变操作方向，不改变图片数据顺序。默认保留条漫和已有翻页、左右手偏好。页面模式默认普通模式。

模式、翻页方式、左右手、页面模式分别保存。阅读位置以漫画和章节为键，保存图片索引与图内偏移；兼容旧版百分比记录。切换布局保留当前图片；从单页跨到下一章打开第一张，返回上一章打开最后一张。

## 实现

- `MainActivity`：二级设置页、阅读入口、章节边界、位置保存和加载生命周期。
- `reader/PagedReaderView`：单页容器、手势和图片视图回收。
- `reader/ZoomImageView`：完整适配、缩放和拖动。
- `reader/ReaderPosition`、`reader/ReaderNavigation`：布局共享的位置和方向规则。
- ViewPager2 1.0.0 / RecyclerView 1.2.1 适配项目现有 AGP 7.4 工具链。应用启用 RTL 支持供左手翻页使用，主界面显式保持原有布局方向。
