## 三、什么叫1:1完成

- 功能：每个Android可达入口和用户结果均在iOS可达，默认值、排序、持久化、取消、失败恢复和数据保护一致。
- 视觉：标题、导航、应用图标/控件图标、主题token、卡片、封面密度、间距、圆角、边框、字号、文案、截断、徽标、抽屉、弹窗、阅读条和加载/空/错态按同尺寸/同内容对照。
- 交互：点击、长按、拖动、缩放、翻页、抽屉展开/关闭、选择/取消、返回路径、键盘、旋转、切后台和重启后的状态一致。
- 不以“同名模块存在”“有单元测试”“编译通过”“UIKit默认样式相似”作为完整替代。缺少实际消费者的核心API仍是未完成。
- 系统差异单列：系统状态栏、键盘、权限、字体栅格化和系统手势可记录必要差异；不能将整套应用导航、图标或布局归为系统差异。
- 文件访问、后台调度、安装更新机制可采用iOS实现，但必须保留同一用户目的及清晰恢复路径。必须无法做到的部分写入差异台账并提供依据与替代；不能默默砍掉。
- 不擅自移除使用统计、图像增强或自动同步等2.0.40能力。依赖外部服务的前段用隔离fixture验证，真实连接在最后整体验收接通。

## 六、阶段完整验收方法

每阶段使用 `docs/ios-parity-2.0.40/STAGE_REPORT_TEMPLATE.md`；P5用同目录`NON_SOURCE_GATE_TEMPLATE.md`形成实际门槛报告，P6用`SOURCE_REPORT_TEMPLATE.md`逐源记录，最后用`FINAL_ACCEPTANCE_TEMPLATE.md`准备用户总验收。阶段报告至少包含：

1. 范围/需求ID与本阶段外部依赖；起止代码版本、fixture版本和构建配置。
2. 实际用户步骤：操作 → 预期结果 → 实际结果，包括异常/取消/恢复，不能只有函数输出。
3. 适当的核心/持久化/HTTP/原生UI测试；记录命令、平台、开始/结束时间、退出码、失败/跳过项及日志。
4. 所有受影响页面在iPhone/iPad、横竖屏、浅深色的实际截图。截图记录逻辑尺寸/像素尺寸、字体缩放、状态数据、提交、哈希；Android/iOS使用相同内容和可比内容宽度。
5. 叠图/差分和逐组件检查：颜色、矩形位置、尺寸、间距、圆角、边框、图标、文案/行数/截断、选中/按压/忙/错态。纯色token按基线精确匹配，普通布局目标误差不超过1逻辑像素；字体栅格化及系统区差异明确记录。
6. 视觉判断不能只靠一个全图相似度百分比。缺按钮、错文案、错误状态和错误触控行为即使图片相似也失败；不得扩大遮罩或修改金标来掩盖。
7. 代码审查：检查实际消费者、默认值、线程、取消代次、持久化、iPad锚点、安全区、重复触发、数据保护及Release隔离。
8. 性能/恢复按场景实际测量：长图、大目录、大文件、增强峰值内存、连续开关、前后台、重启与弱网。Gemini在测试前结合固定Android参考与iOS目标设备设定预算、记录依据，不在失败后降低门槛。
9. 失败先修；通过后更新矩阵/STATUS/differences并自动推进。不让用户审批阶段、不将必需未测写成“已基本完成”。

一个阶段可以因外部环境阻塞暂不通过；同一前段内不依赖阻塞的工作仍可继续，但P5不能假通过，P6不能提前开始。

## 七、最后的真实站源阶段

固定2.0.40源码注册目录包括22个专用站点和29个公共配置驱动站点；毒牙漫画默认关闭，包子/漫画屋退役处理独立保留，不把退役源重新加入搜索。数量表示目录定义，不代表网站当前可用。

- P6开始时从冻结源目录生成 `sources.csv`，保持稳定ID、排序、默认启用、能力限制、网络提示和退役语义。
- 通用注册/配置ID问题属于前段基础接线，前段用fixture检查；真实解析、网站连接/验证与域名变更都留P6。
- 每个源按“目录/ID → 搜索及分页 → 分类 → 详情 → 完整目录 → 首/中/末章节图片 → 还原/Referer/Cookie → 在线与离线 → 导入导出配置 → 错误/取消/验证”完整验收。
- 不支持搜索、仅免费章节、特定线路等以Android基线和站点实际能力记清，不实现越权绕过。验证码/登录要求真实用户授权时列出依赖；不能用模拟Cookie声称真实验证通过。
- 站点变化或不可用：记录日期、网络条件、原始脱敏错误及Android/iOS对照，区分适配器缺陷、站点外部失败和原本能力限制。开发缺陷不能标成站点失效逃避；网站外部阻塞不能谎称可用。
- 当前外部站点需要与冻结业务不同的新域名/接口时，可在同源适配器内修复并记录原因，不增加新站点范围、不改变前段产品交互。
- 每源报告最终适配器版本、可操作入口和实际结果。没有完成一个源就同时铺几十个半成品的做法不符合本方案。
- 每源结束跑受影响回归；全源结束后P7检查公共配置、跨源搜索/换源/追更和下载全链路。
