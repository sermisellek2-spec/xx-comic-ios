XX Comic iOS 2x Anime/Manga Super-Resolution Neural Model
=========================================================

Architecture:
- Compact Residual Convolutional Neural Network with Sub-Pixel Convolution (PixelShuffle x2)
- Input: RGB Image (192x192 tile, matching Android 2.0.40 TILE = 192)
- Output: RGB Image (384x384 tile)
- Parameters: ~50K FP32 parameters (file size: ~198 KB)
- Hardware Acceleration: Apple Neural Engine (ANE) & Metal GPU via CoreML framework
- Memory Guard: Tile-based processing with 64MB LRU cache limit, automatic fallback on thermal throttle (serious/critical) or RAM < 2GB.
